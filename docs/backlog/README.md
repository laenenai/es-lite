# Backlog

Deferred work items that are decided-enough to record but not yet scheduled.
One file per item, named `YYYY-MM-DD_<slug>.md`, with a short header
(filed date, area, status) and acceptance criteria.

Backlog items are lighter than ADRs: an ADR records a *decision and its
rationale*; a backlog item records *work we intend to do*. When a backlog
item is picked up and it involves a load-bearing decision, it usually
graduates into an ADR.
